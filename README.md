# TripForge

TripForge is a production-oriented travel booking platform built as a DevOps and cloud engineering portfolio project.

## Project Goals

The project demonstrates:

- Modern application development
- REST API design
- Containerization
- Kubernetes
- Helm
- GitOps with Argo CD
- CI/CD with GitHub Actions
- Infrastructure as Code with Terraform
- AWS
- Security scanning
- Observability
- Reliability and failure testing

## Architecture

React frontend → FastAPI backend → PostgreSQL
